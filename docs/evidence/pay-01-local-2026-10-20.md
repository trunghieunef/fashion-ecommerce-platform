## Đã làm

- `services/payment-service` mới (port 8086, DB `payment`, role migration/runtime); Gateway route `/admin/api/v1/payments/**`;
  topic `payment.events` (+ DLT); compose, local-up giữ mật khẩu role qua restart, `06-payment-db.sh`.
- Internal cho order-service: create COD → COD_PENDING (`provider_request_id = order_no`), đọc theo order, close + tombstone
  close-before-create; replay create sau close → 409 `PAYMENT_CLOSED`.
- Consumer `shipping.events` (inbox, ACK sau commit): `COD_COLLECTED` khớp → COD_COLLECTED, lệch → `reconciliation_items`;
  `COD_REMITTED` chỉ là bằng chứng (T27); chưa có payment → retry.
- FINANCE: list/detail (`payment.read`), settlement gross = fee + net nhiều đợt (`payment.settle`) → SUCCESS + `PAYMENT_COMPLETED`.
- Event schema `payment-events.schema.json` + registry 3 type + 3 fixture valid + 3 case invalid.
