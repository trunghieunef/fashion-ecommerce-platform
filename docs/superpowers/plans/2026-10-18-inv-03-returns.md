# INV-03 Returns Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** order-service cộng lại `on_hand` cho hàng đã commit, idempotent theo `operation_key`, không vượt tổng commit.

**Architecture:** Route mới trong `ReservationController` (`POST /internal/api/v1/inventory/returns`), service
`ReturnService` trong package `reservation`; một transaction: lock reservation → replay/guard → lock SKU → insert
`stock_returns` + `StockAdminService.move(..., "RETURN", ...)`. Migration V004.

**Tech Stack:** Java 21, Spring Boot 4.0, JdbcClient, Flyway, Testcontainers PostgreSQL 17.11.

**Spec:** [INV-03 design](../specs/2026-10-18-inv-03-returns-design.md)

## Global Constraints

- Caller chỉ `order-service`; 401 → 403 → `Idempotency-Key` (400 `INVALID_KEY`) → body.
- `Idempotency-Key` = `operation_key` (400 `IDEMPOTENCY_KEY_MISMATCH`); 1–100 SKU, qty 1–99, reason/evidence_ref 1–500.
- Ledger key `order:<order_id>:RETURN:<operation_key>`; runtime chỉ SELECT/INSERT `stock_returns`.
- Lỗi: 404 `RESERVATION_NOT_FOUND`, 409 `RESERVATION_NOT_COMMITTED` / `RETURN_CONFLICT` / `RETURN_EXCEEDS_COMMITTED`, 400 `INVALID_INPUT`.

## Review Focus

- `operation_key` dài > 128 hoặc chỉ khoảng trắng → 400 (cột varchar(128)) — Task 1 validation.
- SKU viết thường trong body khớp SKU canonical của reservation — Task 1 test `lowercaseSkuMatches`.
- Hai return song song khác key, tổng > commit → đúng một thành công — Task 1 `parallelReturnsNeverExceedCommit`.
- Return 404/409 không để lại `stock_returns`/ledger — Task 1 assert số dòng.
