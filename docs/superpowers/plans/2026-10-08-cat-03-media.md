# CAT-03 Safe Media Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** OPS upload ảnh JPEG/PNG qua presigned PUT vào quarantine, complete kiểm bytes và
re-encode sang approved/thumb, gắn ảnh vào product/collection theo version, publish product
cần ảnh, đọc ảnh qua Gateway với visibility; job dọn quarantine và asset hết retention.

**Architecture:** Package mới `vn.fashion.catalog.media` trong catalog-service: `MediaStorage`
bọc S3 SDK (I/O luôn ngoài DB transaction), `ImageProcessor` thuần Java/ImageIO, service upload/
attach/read và `MediaJobs`. DB catalog V005 giữ state, lease, fencing và retention; S3 chỉ giữ
bytes với key suy ra từ upload_id và PUT approved dùng `If-None-Match: *`.

**Tech Stack:** Java 21, Spring Boot 4.0 theo BOM repo, JdbcClient, PostgreSQL 17.11 và RustFS
1.0.1 (digest pin) qua Testcontainers, AWS SDK v2 2.55.12 (`s3` + `url-connection-client`, đã có
trong pom), ImageIO built-in; Maven wrapper trong Git Bash, Docker Desktop.

## Global Constraints

- Không JPA, không dependency mới ngoài SDK đã duyệt; không sửa V001–V004; migration V005 append-only.
- Không gọi S3 trong DB transaction hoặc khi giữ row lock; mọi S3 call có timeout (`s3-timeout`, mặc định 10s).
- Mọi route admin kiểm `catalog.write` bằng `AdminAuth.requireCatalogWriter` tại service.
- Request JSON đóng bằng `@JsonAnySetter`, field lạ báo full path (`images[i].<key>`); JsonNode integer không coercion; null field bắt buộc = thiếu.
- Hằng số (code, không config): PUT TTL 300s; `complete_deadline = put_expires_at + 24h`; claim lease 120s;
  bytes 1..5242880; width/height 1..8192; pixels ≤ 25.000.000; approved cạnh dài ≤ 2560; thumb ≤ 800;
  không upscale; 1 slot re-encode/instance; product ≤ 20 ảnh, collection ≤ 50; alt 1–255, caption 0–500
  code point sau strip; sort_order 0..2147483647; retention 7 ngày; sweep 60s/batch 100; GC 1h/batch 100.
- Keys: `quarantine/{id}/raw`, `approved/{id}/image`, `approved/{id}/thumb`. Không nhận URL/key/bucket từ client.
- Không log/lưu presigned URL, credential, object key trong error/audit/metric label.
- Public read: visibility DB quyết định; 304 không gọi S3; 200 GET object, thiếu/lỗi → 503. Readiness không có S3.
- Không provision AWS, không WebP/SVG/GIF, không public browse CAT-02, không DELETE endpoint.
- Gặp mâu thuẫn spec/code/plan hoặc cần quyết định contract mới: dừng phần phụ thuộc và hỏi chủ dự án.

### Task 3: ImageProcessor

**Files:** Create `ImageProcessor.java`, `media/ImageProcessorTest.java` (unit, không Spring/Docker).

**Interfaces:**
- `public record Rendition(byte[] bytes, String contentType, int width, int height, String sha256)` (sha256 hex lowercase).
- `public static class Rejected extends RuntimeException { public String reasonCode(); }` — reason codes của spec §2.
- `static Rendition approve(byte[] raw, String declaredType)` — validate + re-encode, cạnh dài ≤ 2560.
- `static Rendition thumbnail(Rendition image)` — cạnh dài ≤ 800 từ approved image.
- `static Rendition verify(byte[] bytes, String contentType, int maxEdge)` — kiểm object approved thực tế
  (magic, decode, cạnh ≤ maxEdge, size ≤ cap); lỗi → `Rejected("APPROVED_OBJECT_INVALID")`.

Thứ tự trong `approve` (quyết định của plan):
1. `raw.length` 1..5242880 else `IMAGE_TOO_LARGE`; magic bytes JPEG `FF D8 FF` / PNG 8-byte signature khớp
   `declaredType` else `IMAGE_TYPE_NOT_ALLOWED`.
2. `ImageReader` từ `ImageIO.getImageReadersByFormatName`, `setInput(stream, true, true)`, đọc
   `getWidth(0)/getHeight(0)` **trước** `read`; ngoài 1..8192 hoặc `(long) w * h > 25_000_000` → `IMAGE_DIMENSIONS_INVALID`.
3. `read(0)`; mọi `IOException`/`RuntimeException` từ decode (CMYK, truncated) → `IMAGE_DECODE_FAILED`.
4. JPEG: đọc EXIF orientation (tag 0x0112 trong APP1 `Exif\0\0`, TIFF II/MM) và xoay/lật về chiều chuẩn;
   không có/không đọc được → 1. Giới hạn parser chỉ IFD0, offset trong bounds.
5. Scale giữ tỷ lệ, không upscale (`Graphics2D` bicubic). JPEG ghi RGB quality 0.85, PNG ghi ARGB nếu có
   alpha else RGB; encoder không metadata. Output > 5242880 → `IMAGE_OUTPUT_TOO_LARGE`.

11 sau commit (approve/reject): delete(quarantine) best-effort; thành công → quarantine_cleaned_at=now()
