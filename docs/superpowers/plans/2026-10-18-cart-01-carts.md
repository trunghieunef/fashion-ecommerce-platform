# CART-01 — giỏ hàng guest/member Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Service mới `cart-service` lưu giỏ guest (cookie) và member (Bearer) trong PostgreSQL, với API item có version + idempotency và preview giá/tồn tham khảo từ catalog/inventory.

**Architecture:** Spring Boot service riêng, DB `cart`, JdbcClient + Flyway, theo mẫu inventory-service. Danh tính giải quyết một lần mỗi request (`CartActor`); mọi gọi HTTP ra catalog/inventory xảy ra **trước** transaction ngắn khóa giỏ. Preview khi đọc không ghi DB và chịu lỗi dependency.

**Tech Stack:** Java 21, Spring Boot 4.0, JdbcClient, Flyway, platform-durability (`IdempotencyStore`), platform-security (`AccessTokenVerifier`, `ServiceTokenIssuer`), JDK `HttpClient`, Testcontainers PostgreSQL 17.11, JDK `HttpServer` làm stub catalog/inventory trong test.

**Spec:** [`docs/superpowers/specs/2026-10-18-cart-01-carts-design.md`](../specs/2026-10-18-cart-01-carts-design.md) (đã duyệt 2026-10-18).

## Global Constraints

- Port `8084`; DB `cart`, role `cart_migration`/`cart_runtime`; Gateway route `/api/v1/carts/**`; không route admin/internal.
- Cookie `cart_token`: 32 byte ngẫu nhiên base64url (không padding); DB lưu SHA-256 hex; `HttpOnly; Secure; SameSite=Lax; Path=/api/v1/carts; Max-Age=2592000`. Token không vào log/body/metric.
- Bearer hợp lệ → member, bỏ cookie; Bearer lỗi → 401 `UNAUTHORIZED`, không fallback.
- Guest `expires_at = now() + 30 days`, gia hạn mỗi đọc/ghi thành công; quá hạn = không tồn tại. Member không hết hạn.
- Ownership sai/không có/UUID sai → 404 `NOT_FOUND`/`CART_NOT_FOUND`; item lạ → 404 `NOT_FOUND`/`CART_ITEM_NOT_FOUND`.
- Mutation: `expected_version` bắt buộc (400 `VERSION_REQUIRED`), lệch → 409 `VERSION_CONFLICT` + `errors[{field:"expected_version",message:"current=N"}]`; mỗi mutation thành công `version + 1`.
- Add item: `Idempotency-Key` 1–128 bắt buộc (400 `INVALID_KEY`); cùng key + body → response lưu; khác body → 409 `IDEMPOTENCY_KEY_REUSED`.
- quantity 1–99; tổng sau cộng > 99 → 400 `QUANTITY_LIMIT`; item khác nhau thứ 101 → 400 `CART_ITEM_LIMIT`.
- Variant không `found && active` → 409 `VARIANT_NOT_AVAILABLE`; `available < quantity mới` → 409 `OUT_OF_STOCK` + `errors[{field:"quantity",message:"available=N"}]`; catalog/inventory lỗi khi ghi → 503 `TEMPORARILY_UNAVAILABLE`/`DEPENDENCY_UNAVAILABLE`, không ghi.
- Đọc: timeout 1 s mỗi dependency; lỗi → `preview: null`, `preview_status: "UNAVAILABLE"`, vẫn 200.
- Không gọi HTTP khi giữ transaction/row lock. Mọi response `Cache-Control: no-store`.
- Tối đa 100 item; không Redis; không event; envelope `{code,data,metadata}` như service khác.

5. Dependency trả JSON sai shape → coi như lỗi dependency (503 khi ghi, UNAVAILABLE khi đọc), không 500. Test: `CartPreviewIntegrationTest.malformedDependencyResponseIsUnavailable` (Task 5).
