## Bổ sung cho Claude Code

- Code hiện có: `services/cart-service` (giỏ guest cookie/member Bearer, checkout token guest cho order, gọi catalog quote + inventory stock bằng service token; merge guest→member, internal snapshot/checkout-cleanup cho order-service), `services/catalog-service` (admin taxonomy/product/variant/collection/size guide, media S3 private, public browse/search và internal quote), `services/user-service` (auth, địa chỉ, role/permission, admin/audit), `services/inventory-service` (đăng ký SKU từ event, stock/ledger, OPS adjust/import CSV, internal stock read, reserve/commit/release và return hàng đã commit), `services/shipping-service` (SHP-01: rule phí SELF, estimate/quote, shipment SELF, OPS rules/shipments; SHP-02: OPS self-events có bằng chứng, COD thu/nộp, cancel + tombstone), `services/payment-service` (PAY-01: payment COD một/đơn, close + tombstone, bằng chứng COD từ `shipping.events`, FINANCE settlement gross-fee-net; chưa VNPay/MoMo/refund), `services/order-service` (ORD-01: quote ký 2 phút, tạo đơn PENDING idempotent có snapshot, đọc đơn member/guest; guest dùng checkout token do cart ký; ORD-02: saga worker nền lease+CAS reserve → payment COD → CONFIRMED, bù trừ/hết hạn → CANCELLED, dọn giỏ background task, inbox `payment.events`; ORD-03: admin orders `/admin/api/v1/orders` (PII chỉ với order.fulfill), OPS confirm-cod/cancel đơn chờ OPS, saga COMMIT_STOCK (inventory là trọng tài hạn) → PACKING → CREATE_SHIPMENT SELF, consumer `shipping.events` → SHIPPING/DELIVERED + ORDER_COMPLETED; ORD-04 (Done local): khách tự hủy đơn chờ OPS + `allowed_actions`, OPS hủy tới trước bàn giao với bù trừ vận đơn → kho (`/returns` `cancel:{order_id}`) → payment, hoàn hàng `RETURNING`/`WAIT_RETURN`, phiếu kiểm đếm `POST /admin/api/v1/orders/{order_no}/returns` (`order.return`) cộng kho một lần → `RETURNED`; refund tiền đã thu chờ PAY-04), `services/notification-service` (NOT-01, Done local: 6 email giao dịch VI/EN qua SMTP; consumer `notification.events` → `notifications` PENDING snapshot đã escape, worker lease 120 s, retry/FAILED/UNKNOWN/EXPIRED, reset email lấy token từ user internal lúc gửi, không lưu token; order phát `NOTIFY_ORDER_*` trong `OrderTransitions.move`; user-service bật relay; local dùng Mailpit `127.0.0.1:8025`; chưa provider thật O07), `services/gateway` (route public/admin, CSRF và ranh giới internal), `web/storefront` (WEB-01/01b: home/listing/search/collection/detail VI/EN; WEB-02 Done local: đăng nhập/tài khoản/địa chỉ, giỏ hàng và gộp giỏ; WEB-03 Done local: checkout COD, trang đơn, đơn của member). Trạng thái nghiệm thu từng task theo backlog, không suy ra MVP đã hoàn thành.
- Thư viện dùng chung: `services/platform-durability` (outbox/inbox/idempotency/lease), `services/platform-security` (service token ADR-19/JWT), `services/platform-messaging` (Spring Kafka relay, inbox consumer, retry/DLT/metrics). `infra/local/compose.yaml` có PostgreSQL, Redis, RustFS và Kafka KRaft local; catalog relay phát VARIANT_CREATED, inventory tiêu thụ và phát stock snapshot qua outbox.
